# 📊 Social Media Sentiment Analysis Dashboard

An interactive **Social Media Sentiment Analysis Dashboard built in Microsoft Excel** to analyze social media posts based on sentiment, engagement, toxicity, platforms, topics, categories, and time periods.

The dashboard provides a visual overview of social media performance and helps identify engagement patterns, sentiment distribution, trending topics, and areas requiring attention.

## 📖 Project Overview

Social media platforms generate large volumes of user-generated content every day. Understanding the sentiment, engagement, toxicity, and topics within these posts can help identify trends and understand how audiences interact with different types of content.

This project presents an Excel-based dashboard that analyzes **2,201 social media posts** and converts the underlying data into interactive visual insights.

The dashboard focuses on:

- Social media platform performance
- Engagement analysis
- Sentiment distribution
- Toxicity levels
- Topic performance
- Category-wise engagement
- Monthly and weekly trends
- Platform-wise sentiment
- Trending topics
- High-engagement and high-toxicity areas

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze social media post engagement.
2. Understand positive, negative, and neutral sentiment distribution.
3. Compare performance across social media platforms.

5. Analyze toxicity levels across topics.
6. Identify engagement trends over time.
7. Create an easy-to-understand visual dashboard in Excel.
8. Provide an executive-level summary of the analyzed social media data.

## 📈 Dashboard Components

### 1. Platform Analysis

The dashboard compares social media platforms based on:

- Number of posts
- Engagement
- Sentiment
- Overall platform performance

This allows users to understand how activity and engagement vary across platforms.

---

### 2. Weekly Engagement Analysis

The weekly engagement visualization shows how engagement changes throughout the week.

This can be used to identify:

- High-engagement days
- Low-engagement days
- Weekly engagement patterns
- Potential opportunities for content scheduling

---

### 3. Platform-Wise Engagement

A platform comparison is provided to examine differences in engagement across social media channels.

This helps identify platforms generating relatively higher levels of audience interaction within the analyzed dataset.

---

### 4. Category-Wise Engagement

The dashboard includes a category-level engagement analysis.

Categories can be compared to determine which content groups receive higher levels of interaction.

---

### 5. Trending Topics

The trending-topic section highlights topics associated with engagement.

This provides a quick way to identify subjects that attract audience attention within the dataset.

---

### 6. Platform-Wise Post Analysis

The dashboard compares the number of posts across platforms.

This helps understand how the dataset is distributed across different social media channels.

---

### 7. Sentiment Distribution

The sentiment distribution visualization categorizes posts into:

- Positive
- Negative
- Neutral

The dashboard shows:

- Positive sentiment: **33.48%**
- Negative sentiment: **32.40%**
- Neutral sentiment: **32.40%**

The distribution indicates that the three sentiment categories are relatively close in proportion.

---

### 8. Topic-Wise Toxicity Analysis

The dashboard analyzes toxicity scores across different topics.

This helps identify topics associated with comparatively higher toxicity levels and provides an additional dimension beyond simple sentiment classification.

---

### 9. Platform Sentiment Analysis

Platform-level sentiment analysis compares sentiment patterns across social media platforms.

This can help identify differences in the sentiment composition of posts from different platforms.

The summary highlights:

## 📌 Data Disclaimer

The dashboard metrics and observations are based on the dataset used for this project.

The dashboard should be treated as an analytical visualization rather than a representation of all social media activity. The results depend on the quality, size, time period, and composition of the underlying dataset.

Toxicity and sentiment scores should also be interpreted as analytical classifications rather than definitive judgments about individual users or posts.
